# Accueil du TP — Wiki collaboratif

## Présentation
Ce dépôt est réalisé dans le cadre du TP3 sur l'utilisation avancée d'un Wiki pour la gestion collaborative et la documentation technique. Le thème documentaire choisi est un exemple fictif : « Système d'alerte IoT pour la détection de fumée ».

**Important :** le TP porte sur la création et la gestion collaborative du Wiki. La réalisation matérielle du système IoT n'est pas demandée. Les descriptions et le petit programme de simulation servent uniquement d'illustration.

## Objectifs du TP
- Créer une page d'accueil et structurer les pages.
- Préparer et utiliser un modèle de page pour les modules.
- Classer les pages avec un index de catégories.
- Ajouter des contributeurs et suivre leurs modifications.
- Valider les changements par discussion.
- Consulter l'historique des pages.
- Créer un sommaire, une infobox et des liens internes.
- Présenter une carte de navigation.

## Sujet documentaire
Le système fictif est décrit à travers trois parties : capteur et acquisition, communication IoT, interface utilisateur. Les exemples sont documentaires et simulés ; aucun montage électronique ni serveur IoT réel n'est requis pour ce TP.
