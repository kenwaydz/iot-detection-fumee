# Bilan du TP3 — Wiki collaboratif

## Objectif
Le TP avait pour objectif d'utiliser un espace documentaire collaboratif pour structurer et gérer une documentation technique.

## Travail réalisé dans le Wiki
- Création d'une page d'accueil.
- Création d'un modèle de page pour décrire les modules.
- Organisation des pages et index de catégories.
- Création de pages décrivant les trois modules du scénario IoT.
- Ajout d'une infobox, d'un sommaire et de liens internes.
- Préparation d'une carte de navigation.
- Organisation du travail à trois et suivi des contributions par GitHub.
- Préparation d'une simulation logicielle simple pour illustrer les exemples.

## Collaboration et traçabilité
Décrire les invitations, les modifications réalisées par chaque membre, les discussions de validation et les commits réellement visibles dans l'historique GitHub.

## Tests documentaires
Les tests concernent uniquement la simulation HTML et la vérification des liens/pages du Wiki. Aucune réalisation matérielle IoT n'est requise dans ce TP.

## Difficultés rencontrées
À compléter selon les difficultés réelles de l'équipe.

## Conclusion
Le TP a permis de pratiquer la structuration d'une documentation, la collaboration, la validation des modifications et le suivi de l'historique avec GitHub.
