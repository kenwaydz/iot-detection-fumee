# Scénarios de test

## Test 1 – Fonctionnement au repos
- Action : alimenter le système dans un environnement normal.
- Attendu : les mesures sont lues sans alerte injustifiée.

## Test 2 – Détection
- Action : effectuer un test contrôlé et sûr, selon les consignes de l'encadrant.
- Attendu : la mesure évolue et le système identifie le dépassement du seuil configuré.

## Test 3 – Transmission
- Action : vérifier la réception d'une mesure sur la plateforme.
- Attendu : le message est reçu et interprété correctement.

## Test 4 – Notification
- Action : déclencher un événement de test.
- Attendu : l'interface ou le service affiche l'alerte.

## Test 5 – Perte réseau
- Action : interrompre temporairement la connexion.
- Attendu : le comportement lors de la déconnexion est documenté et la reconnexion est vérifiée si elle est implémentée.

**Sécurité :** ne pas utiliser de flamme ni créer une situation dangereuse. Suivre les méthodes de test validées par l'enseignant.
