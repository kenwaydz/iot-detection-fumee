## Ajouter des collaborateurs
Dans GitHub : ouvrir le dépôt → Settings → Collaborators (ou Collaborators and teams) → Add people. Les personnes invitées doivent accepter l'invitation.

## Discussions
GitHub repository Markdown ne fournit pas une discussion intégrée à chaque page. Utiliser Discussions si la fonctionnalité est activée, ou Issues pour les propositions et validations.

## Historique
Chaque fichier possède un historique Git. Ouvrir le fichier puis cliquer sur History pour identifier les auteurs, dates et commits.
