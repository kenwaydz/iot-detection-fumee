# Système d'alerte IoT pour la détection de fumée

> TP3 – Wiki collaboratif avancé – Groupe 3 (IMSI)

Ce projet documente un système IoT capable de détecter la fumée dans une pièce et d'envoyer une alerte via une plateforme connectée.

## Architecture
- Capteur MQ-2
- Microcontrôleur Arduino ou ESP32
- Passerelle Wi-Fi ou MQTT
- Interface web ou mobile
- Base de données des événements
